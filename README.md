# JinkelaCrops — Research & Engineering

Personal website: https://jinkelacrops.github.io/

The supplied HTML prototype is retained as the design basis. The site supports Chinese/English, light/dark themes, responsive cards and expandable outlines. Proposed projects and notes remain explicitly marked as plans.

## Edit and publish

Edit `src/index.html`, `src/site.css`, and `src/site.js`. Run `python src/build.py`, then `python -m unittest discover -s test`. Commit generated `index.html` and `assets/` along with source. GitHub Pages serves the root of `master`; no external dependencies or tracking services are required.
